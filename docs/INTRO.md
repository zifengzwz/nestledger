# 小家有账 · NestLedger 项目简介

## 一句话介绍

NestLedger（小家有账）是一套面向个人与小家庭的记账系统：用手机号登录，按个人账本或家庭账本记录收支，自动生成周／月／年分析，数据保存在自己的服务器上。

## 解决什么问题

- 家庭开支常分散在多个人的手机里，缺少一个共同查看、共同记录的入口。
- 公共记账 App 往往把数据放在第三方云端，隐私和长期可用性不可控。
- 表格记账灵活但统计麻烦，手机端输入体验差。

NestLedger 把「多人共享的家庭账本」和「只属于个人的私密账本」放在同一套界面里，支持邀请已注册家人加入家庭账本，成员之间共享记录，个人账本彼此不可见。

## 主要功能

- **账号与安全**：手机号注册、密码登录、退出；修改密码、更换绑定手机号；忘记密码通过短信验证重置，重置后其他设备的旧会话立即失效。
- **个人与家庭账本**：可创建多个账本并随时切换；家庭账本通过手机号邀请已注册用户，支持接受／拒绝、移除成员、成员退出；个人账本默认仅本人可见，所有者也可只读分享给指定用户。
- **只读分享**：账本所有者可按手机号把账本分享给指定已注册用户；对方在「我的邀请」中接受或拒绝，接受后以只读身份查看记录和分析，不能修改或导出；拥有者可随时取消，也可在被拒绝后重新发送。
- **收支记录**：收入／支出、金额、分类、支付方式、日期、备注；搜索、筛选、分页、编辑与删除；金额以整数分存储，避免浮点误差。
- **自定义选项**：分类和支付方式可在记账时直接新增，选择图标后保存到账号，跨设备可用；每类最多 50 项。
- **导入导出**：当前账本支持 CSV／JSON 导出与 CSV 模板；导入先预览、服务端整批校验，再确认追加；单次 1–5000 笔，防重复提交。
- **统计分析**：按 Asia/Shanghai 时区的自然周、月、年统计收入、支出、结余、记录数、趋势和支出分类排名。
- **个性化**：11 套界面色调（含 3 套高对比），切换后同步到账号；账本列表支持拖拽／上下移动排序，顺序按账号保存。
- **响应式界面**：桌面侧栏与手机抽屉导航，中文界面，包含加载、错误重试、空态和确认弹窗。

## 设计特色

- **隐私优先**：所有数据存放在部署者自己的 MongoDB 中，不依赖第三方记账云服务。
- **家庭协作但不越权**：家庭成员可查看和新增记录，只有记录创建人或账本所有者能修改、删除；个人账本对其他账号完全隔离。
- **注册门槛可控**：邀请只能发给已注册手机号；注册需要短信验证码和本地图形验证码，短信验证码 5 分钟有效、限频、限次。
- **默认安全**：HTTPS、HttpOnly + SameSite=Lax Cookie、Origin／JSON 校验、CSP、HSTS、数据库密码认证、PBKDF2-HMAC-SHA256（60 万次迭代）。
- **轻量部署**：单机 OpenResty + MongoDB + Redis，无容器依赖；前端在构建机打成发布包，部署机不需要 Node/npm。

## 技术架构

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3、TypeScript、Vite、Lucide 图标 |
| 接入层 | OpenResty（Lua + cosocket），同源托管静态页面与 `/api` |
| 数据层 | MongoDB（用户、账本、记录、邀请、只读分享、导入回执，整数分与 BSON 原生编码） |
| 会话与限流 | Redis（HttpOnly Cookie 会话、验证码、各类频率限制） |
| 安全 | SCRAM-SHA-256 连接数据库、PBKDF2 密码哈希、TLS 1.2/1.3、CSP/HSTS、严格的 Origin 与 JSON 校验 |
| 测试 | Vitest、Python 集成测试、Playwright 桌面／手机端到端测试 |

后端直接使用 OpenResty cosocket 实现 MongoDB OP_MSG 协议与 Redis 客户端，不引入 Node 或 Python 业务运行时。

## 环境与访问地址

| 环境 | 地址 | 说明 |
| --- | --- | --- |
| 测试 | `https://127.0.0.1:8443` | 本机自签名证书，自动生成 |
| 发布 | `https://xxx.com:8001` | TLS 证书由运维单独提供 |

部署机只需 OpenResty、MongoDB、Redis、Python 与 openssl；Node.js/npm 仅用于构建机生成发布包。

## 适用场景

- 想在自己的服务器或家里的小主机上长期运行一套家庭记账工具。
- 希望家庭成员共同记账，但个人账目保持独立。
- 重视数据归属，希望可备份、可迁移、不依赖第三方服务。
