# 小家有账 · 界面美化

界面提供 **8 套可选色调**（4 套沉稳＋4 套鲜艳），默认陶土暖棕，用户可在「账户与安全 → 界面色调」切换并同步到账号。详见[界面色调](THEMES.md)。所有配色仅调整视觉样式，业务流程、布局尺寸与交互保持不变。

## 配色方案

| 色调 | 主色 | 结余卡 | 收入色 |
| --- | --- | --- | --- |
| 陶土暖棕（默认） | `#965438` | 深海咖啡棕 | 橄榄绿 |
| 森林青绿 | `#2f6b4f` | 深墨绿 | 草绿 |
| 雾蓝浅灰 | `#386d96` | 深海蓝 | 雾蓝 |
| 烟紫暮色 | `#7a4f7c` | 深茄紫 | 灰绿 |
| 珊瑚橙 | `#e0583a` | 深咖啡红 | 墨绿 |
| 芒果黄 | `#e29410` | 深琥珀 | 墨绿 |
| 薄荷青 | `#0f9c8e` | 深松石 | 翠绿 |
| 莓果红 | `#c9256a` | 深酒红 | 松绿 |

- 颜色通过 CSS 变量与 `data-theme` 切换，浅色底纹由主色 `color-mix` 派生。
- 收入语义色与主操作色区分，支出保持暖杏／琥珀，删除保持红色。
- 8套主题的**正文、标题、金额与表格文字统一近黑色**，主题色只用于按钮、图标、浅底与装饰；对比度经浏览器自动校验，最弱项≥4.9:1，正文≥15:1。
- 基础字号15px、行高1.6，卡片纯白纸面，卡片边框更清晰。

## 主要变化

- **颜色与背景**：奶油白、浅绿柔和背景，森林绿作为主操作与结余焦点。
- **统计卡片**：收入浅绿、支出奶杏、结余深绿白字，增强层级；金额保留完整精确值、使用等宽数字排版。
- **导航与操作**：侧栏选中项增加色条和柔和底色；记一笔更突出，导入／导出、邀请等次操作更轻盈。
- **卡片与表格**：统一圆角、边框、轻阴影、表头和悬停反馈，增加小字对比度。
- **弹窗与表单**：登录、账户、管理、分类／图标选择、导入导出采用一致视觉体系，不改API或数据。
- **手机**：收入／支出两列、结余跨列；320px小屏自动单列。金额列固定在记录表右侧，滚到末尾仍可编辑／删除；表格其他字段可横向滚动查看。

## 侧栏字号

左侧导航文字整体上调，提升可读性：

| 元素 | 原字号 | 现字号 |
| --- | --- | --- |
| 品牌名称 / 副标题 | 19px / 9px | 21px / 10px |
| 导航项 | 13px | 14.5px |
| 账本名称 | 12px | 13.5px |
| 账本类型标签 | 9px | 10px |
| 区块标题 / 排序按钮 / 提示 | 10px | 11px |
| 账号名 / 副标题 | 12px / 10px | 13.5px / 11.5px |
| 侧栏提示卡 | 12px / 10px | 13px / 11.5px |

账本行高仍为48px、列表高度240px（五行），导航按钮无文字截断，320px手机抽屉内也无横向溢出。

## 保持不变

- 账本行高48px、列表最大240px（同时最多显示5行）。
- 筛选控件与按钮高40px，筛选／重置与结束日期保持对齐。
- 全部接口、字段、精确金额、角色权限、图标选择、账号设置、导入导出、排序和邀请逻辑。
- 不加载外部字体／图片／CDN，不新增依赖；保留减少动画偏好与键盘焦点样式。
