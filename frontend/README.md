# 小家有账 · NestLedger 前端

Vue 3 + TypeScript + Vite 中文响应式应用，手写 CSS、Lucide 图标和 SVG 趋势图。仅真实 API 集成，不提供演示数据或请求失败时的假数据回退。

## 启动与验证

```bash
cd frontend
npm install
npm run dev
npm run build
npm test
```

建议 Node.js 22.12+ 或 24 LTS。开发服务器默认使用 Vite 端口 5173，`/api` 代理至 `https://127.0.0.1:8443`（接受本机自签名证书）。如需修改后端地址：

```bash
API_PROXY_TARGET=https://127.0.0.1:8443 npm run dev
```

注意：Vite 页面为 http 源，后端会话 Cookie 带 Secure 标记，登录态不会保存在浏览器；完整流程请使用 OpenResty 的 HTTPS 同源构建。

生产构建位于 `dist/`，由项目的 OpenResty 同源提供静态文件；所有请求使用相对 `/api` URL 和 `credentials: 'include'`。所有写操作发送 JSON，包括空参数的注销、删除、接受/拒绝邀请，以满足后端 CSRF 防护。请不要将开发服务器直接暴露在不可信网络。

## 功能

- 手机号注册、密码登录、会话恢复、注销、修改密码/手机号。
- 多个个人/家庭账本切换、新建、更名、删除（删除需确认）；左侧可见列表最多5行，超过5本滚动查看，当前账本高亮，支持方向键/Home/End切换。点击“排序”进入拖拽／上移／下移模式，调用PATCH /books/order自动保存账号级顺序，保存失败回滚，完成后返回账本选择模式。
- 家庭成员列表、拥有者手机号邀请、成员移除/自行退出、邀请接受/拒绝。
- 收入/支出新增、编辑、删除；时间、分类、金额、备注、支付方式；筛选、搜索、分页。
- 账本CSV／JSON下载、日期过滤、CSV模板；文件本地解析预览、服务器dry-run校验、手动确认追加。支持BOM、带引号逗号／多行、精确金额和严格日期，危险单元格有Excel公式防护，JSON备份优先保真；单次1–5000笔／10MiB，不自动导入或覆盖，当前文件失败重试保留requestId。
- 分类和支付方式标题旁“添加”打开内嵌编辑区，可输入名称并从35个图标中选择，保存常用自定义选项后自动选中，不提交或清空记账草稿。收入分类／支出分类／支付方式分别按账号持久化，默认项保留，每种自定义上限50个，名称1–40字；重复或保存失败显示错误，取消添加可继续记账。每次打开记账弹窗重新加载账号选项，支持跨设备同步。
- 自然周/月/年分析、日期切换、收入/支出/结余卡片、SVG 趋势图、可展开无障碍趋势数据表、支出分类占比。
- 个人账本仅本人；管理操作仅拥有者；记录编辑删除仅创建者或拥有者。后端仍必须进行最终权限校验。
- 分类／支付方式对应本地SVG图标，输入框、下拉、记录列表和支出分类分析同步显示；自定义项使用所选图标，历史未选图标时通用回退；选择器支持点击、触摸和方向键，图标为装饰性、不替代文字和无障碍名称，不修改API或Mongo字段。
- 8套可选色调（4套沉稳：陶土暖棕／森林青绿／雾蓝浅灰／烟紫暮色，4套鲜艳：珊瑚橙／芒果黄／薄荷青／莓果红），通过CSS变量与`data-theme`切换；账户页选择后立即生效并PATCH到账号，localStorage预加载避免刷新闪烁，非法值回退默认。固定桌面侧栏、手机抽屉导航、响应式卡片与可横向滚动明细表。
- 明确空态、加载态、错误重试、toast、确认弹窗；弹窗支持 Esc、焦点陷阱、关闭后焦点恢复；所有图标按钮有可访问名称。

**手机号邀请不发送短信，且只允许已注册手机号。** 未注册号码会显示“该手机号尚未注册，请对方先注册后再邀请”，不会留下待接受邀请。已注册用户登录后，在平台内「我的邀请」中接受。手机号变更使用当前密码验证，不提供短信验证码；界面在相关入口明确说明。

金额以整数分与 API 通信，金额输入限制两位小数、正数和契约上限。显示与输入时间按 Asia/Shanghai 处理，不依赖设备时区；筛选结束日转换为次日零点（API `to` 为排他上界）。

## 源码与测试

- `src/api.ts`：共享契约类型、cookie/JSON 传输、网络与服务错误。
- `src/utils.ts`：整数分转换、北京时间日期、权限展示判断。
- `src/App.vue`：认证、侧栏、记录、分析、成员/邀请、账户流程。
- `src/components/Modal.vue`：键盘可访问弹窗。
- `src/components/TrendChart.vue`：SVG 趋势图。
- `src/tests/`：Vitest 单元与组件/应用 API 流程测试，使用仅测试域内的 fetch mock。

生产应用无 localStorage token、无 hardcoded 示例账目、无第三方字体或图片网络依赖。
